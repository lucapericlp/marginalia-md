Marginalia adds paragraph and passage notes to the margins of your ordinary Obsidian notes. Annotations are readable Markdown footnotes, so the text stays useful without the plugin.

- Use margin notes in Live Preview, Source mode, and standard Reading view.
- Mark a whole paragraph with a fine bracket, or a selected passage with a soft highlight.
- Keep your theme's main text styling and native Vim editing.
- Edit comments in the margin; carry unsaved drafts between views.
- Move notes beneath their paragraph in narrow panes.

This is the first public release. It includes Community Plugins assets, an MIT license, dependency notices, and automated release checks. Requires Obsidian 1.14.4 or newer. Desktop interactions have been tested; mobile has not yet been verified.

The Community Plugins listing requires a separate directory submission and review. Until it is listed, install through BRAT using `lucapericlp/marginalia`, or download `marginalia-0.3.1.zip`, copy its `marginalia` folder into your vault's plugin directory, and enable Marginalia in Community plugins. The individual `main.js`, `manifest.json`, and `styles.css` assets are also attached for Obsidian's installer.
