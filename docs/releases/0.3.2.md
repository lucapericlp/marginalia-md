Marginalia MD is the new name and plugin ID for this project. The repository is now `lucapericlp/marginalia-md`.

- The Community Plugins ID is `marginalia-md`; the display name is **Marginalia MD**.
- The manual-install package is `marginalia-md-0.3.2.zip`, containing a `marginalia-md` folder.
- Repository links, BRAT instructions, package metadata, release automation, and submission instructions use the new name.
- Existing paragraph and passage annotations keep their Markdown format and work unchanged.

**Upgrading a previous private build:** disable the old **Marginalia** plugin before enabling **Marginalia MD**, so both versions do not annotate the same note. Saved comments already live in your Markdown files and need no migration. If you have unsaved margin drafts, disable the old plugin first and copy its `data.json` into the new plugin folder before enabling the new version. Keep the old folder until you have confirmed the upgrade.

Requires Obsidian 1.14.4 or newer. The Community Plugins directory submission and review are separate from this GitHub release. Until listed, install through BRAT using `lucapericlp/marginalia-md` or use the attached ZIP. The separate `main.js`, `manifest.json`, and `styles.css` assets are supplied for Obsidian's installer.
