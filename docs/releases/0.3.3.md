This release addresses the Community Plugins automated review findings.

- The default build and release build now produce identical `main.js` files.
- GitHub build-provenance attestations cover `main.js`, `manifest.json`, and `styles.css`.
- Only those three supported assets are attached to the release. Optional manual packages remain available from the workflow artifacts or a local build.
- Styles no longer use `!important` or partially supported text-decoration properties.
- Wide editor margin panels render outside Obsidian's paint-contained widgets; compact panes keep notes below their paragraphs.
- CI checks CSS compatibility and build reproducibility alongside the existing source tests.

Existing annotations remain compatible. Requires Obsidian 1.14.4 or newer. This GitHub release does not publish the Community Plugins listing.
